# RedBolt

RedBolt is a C# port of rbfx. The current bootstrap stage validates native dependency builds and automated SharpCpp binding generation described in `doc/`.

## Binding Policy

RedBolt uses automated bindings only. Dependency bindings are generated by SharpCpp from clang-parsed SDL and Diligent headers. Do not add hand-authored C/C++ facade headers, C ABI forwarding functions, P/Invoke declarations, or C# wrapper binding classes for dependency APIs.

Hand-authored RedBolt code belongs above the generated interop layer as engine/runtime API, not inside the binding layer. Generated C# and C++ files stay in the CMake build tree.

## Stage 0 Build

```bash
cmake --preset dev
cmake --build --preset Debug
```

The `Debug` preset builds the `redbolt-stage0` target, which verifies:

- rbfx and SharpCpp source roots are present.
- SDL builds from RedBolt's copied third-party source as a native dependency.
- Diligent graphics headers compile through a RedBolt dependency smoke target.
- `RedBolt.Dependencies.Generator` runs SharpCpp over clang-parsed dependency headers, including SDL headers from `out/build/dev/deps/SDL/include` after the SDL build target is available.
- `RedBolt.Native` compiles only SharpCpp-generated native thunks needed by generated bindings.
